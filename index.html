Network Troubleshooting (PC-Mill)

SPUD Controller Diagnostics

SPUD Controller (PC-Mill)

SPUD REQUIRES A CROSSOVER CABLE.

Standard off-the-shelf patch cables will not work. A crossover cable has Green and Orange pairs swapped (Pins 1 & 2 swapped with 3 & 6).

1. External Cable Bypass Check

Connect your proven 100ft external CROSSOVER network cable directly from the network port on the desktop PC to the machine control port. If communication is restored, the issue is an internal cable failure.

2. Power Down and Reseat Physical Connections

Power down the machine entirely. Reseat the network cable at the computer network port and at the machine control port. Ensure you are grounded, then remove and carefully re-seat the Flash card into the Mill PC (CPU board).

3. Verify Windows Static IPv4 & Ping

Verify the Windows PC's Network Adapter is holding its assigned Static IP address. If the PC has defaulted to a DHCP/APIPA address (169.254.x.x), communication will fail.

Turn the machine on. Open Command Prompt and attempt to ping the machine's communication IP address by typing: ping 192.0.0.47. If it times out or fails, proceed to Step 4.

4. Verify the Windows HOSTS File

Navigate to C:\Windows\System32\drivers\etc. Open Notepad as an Administrator, then open the `hosts` file.

You must verify the presence of the following exact line at the bottom: 192.0.0.46 PC MILL. (Note: .46 is the proxy IP, which differs intentionally from the .47 machine IP). If this is missing or commented out (has a # in front of it), correct it and save.

5. CPU Board Environmental & Hardware Check

Unplug the flash card and re-seat it into the CPU board one more time, then test. If it still fails, the CPU board itself is the likely culprit. Inspect the cooling fan/heatsink on the CPU board. In hot manufacturing environments without AC, these fail, causing the board to overheat.

Heatsink/Fan Area
Flash / Storage Interface

Reference: CPU Board layout. If the shop floor runs a box fan aimed at the cabinet, a heat failure is highly probable.

Mandatory Escalation Policy

Do not escalate to Startup Managers or the Applications Manager until you have confirmed ALL of the following:

  • Tested physical connection using a known-good external 100ft cable.
  • Verified correct cable type is used (Crossover for SPUD).
  • Completed all controller-specific ping tests and configuration checks.

Aldebaran Architecture & Mill-Proxy

Aldebaran Hardware Architecture

User Computer (Windows PC)

Windows based PC. Minimum specs: Intel i5 2.8Ghz, Intel P67 B3 Motherboard, 500W Ultra-LSP PSU, 8GB Dual Channel RAM, Dual NICs (1 integrated, 1 external).

WARNING: strictly for machine control. Tarus does not recommend ANY external software be installed.

Mill Computer (Embedded)

Embedded computer running a real-time OS (RTOS) providing low level fast control. Uses a Flash Card inserted into the Mill PC. Constant interaction between these two computers uses mill_proxy.

1. External Cable Bypass Check

Connect your proven 100ft external STRAIGHT-THRU network cable directly from the network port on the desktop PC to the machine control port. Also reseat the Flash card on the Mill PC.

2. Verify Static IPv4 Settings & Ping

Open Control Panel > Network and Sharing Center > Ethernet Properties > IPv4 Properties. The User Computer must have a fixed IP address for the network card communicating with the mill.

Required IP: 192.0.0.47 | Subnet: 255.255.255.0

3. Verify Proxy Services

Open Windows Services (services.msc). Scroll down to locate the `Mill-Proxy` service. Verify Status is Running. Check that Windows Firewall is not blocking the application.

Protocol 2: Windows Power & Adapter Optimization

Windows energy-saving features can inadvertently interrupt the continuous network "heartbeat" required by Mill-Proxy. These settings must be disabled to ensure stability.

  1. Set Power Plan to High Performance: Navigate to Control Panel > Power Options. Select High Performance.
  2. Disable Sleep and Display Shutoff: Click Change plan settings. Set Turn off the display to Never and Put the computer to sleep to Never.
  3. Advanced Power Settings: Hard Disk: Click Change advanced power settings. Expand Hard disk > Turn off hard disk after. Change Setting (Minutes) to 0 (Never).
  4. Disable Network Adapter Power Management: Open Network Connections. Right-click the Machine Control adapter > Properties > Configure > Power Management tab. UNCHECK "Allow the computer to turn off this device" and "Only allow a magic packet to wake".
  5. Disable Energy Efficient Ethernet (EEE): In the same adapter window, go to the Advanced tab. Find Energy Efficient Ethernet. Change Value to Off. Click OK.

Diagnostic Logs: Mill Proxy Terminal

The terminal for the Machine (Motion Control computer) and the User PC (Operator stations) is called Mill Proxy. This window is a terminal that shows information being passed while the PC communicates with the machine computer.

This task will show an icon in the System Tray while the machine is in operation and the connection between the user computer and the "Mill" computer is active.

Note: The user does not have any control over this window. This window can help service the machine quicker if there are errors or problems with the machine. Those error codes will be running through the "Mill Server" window.

How to Save the Log File

A log file of the messages in this window can be saved out and sent (email) to Tarus for evaluation. To save out the log file, click on the camera button (Snapshot) located on the top left of the window.

This log file is located in the following folder:

C:\Tarus Products\LogFiles

There will be multiple files that are saved to this directory. All files are Text (txt) documents and can be viewed in any text reader program (i.e. Notepad or WordPad) and/or emailed to Tarus for further evaluation.

  • Tested physical connection using a known-good external 100ft cable.
  • Verified correct cable type is used (Standard Straight-Thru).
  • Completed all controller-specific ping tests, proxy checks, and power optimizations.

TarusNC (S-Proxy) Troubleshooting

NO HOSTS FILE.

TarusNC does not use the Windows HOSTS file at all. Troubleshooting is strictly reliant on physical routing (Column PC to NCU) and correct IP/Proxy configurations.

1. Physical Port Identification Check

Because PCs often have multiple ports, you must verify you are plugged into the correct one. Open Control Panel\Network and Internet\Network Connections. As you plug the cable into the machine control port, watch the screen to ensure the specific adapter configured as "Machine Control" begins to initialize.

2. Network Machine Control IP Check

Right-click the Machine Control adapter and select Properties > IPv4. Verify the IP address is strictly configured as 192.168.214.55 with a subnet of 255.255.255.0. If it does not match, correct it immediately.

3. S-Proxy Communication Settings Check

We install SINUMERIK_OPERATE_pc.exe as Administrator. Open Windows Control Panel (View by: Small icons), look for Communication Settings and launch it. Select Access points. Expand S7ONLINE and verify the Machine Control adapter is assigned to Intel(R) Ethernet Controller I226-V. TCPIP.AUTO. 1.

Protocol 2: Windows Power & Adapter Optimization

Windows energy-saving features can inadvertently interrupt the continuous network "heartbeat" required by S-Proxy. These settings must be disabled to ensure stability.

  1. Set Power Plan to High Performance: Navigate to Control Panel > Power Options. Select High Performance.
  2. Disable Sleep and Display Shutoff: Click Change plan settings. Set Turn off the display to Never and Put the computer to sleep to Never.
  3. Advanced Power Settings: Hard Disk: Click Change advanced power settings. Expand Hard disk > Turn off hard disk after. Change Setting (Minutes) to 0 (Never).
  4. Disable Network Adapter Power Management: Open Network Connections. Right-click the Machine Control adapter > Properties > Configure > Power Management tab. UNCHECK "Allow the computer to turn off this device" and "Only allow a magic packet to wake".
  5. Disable Energy Efficient Ethernet (EEE): In the same adapter window, go to the Advanced tab. Find Energy Efficient Ethernet. Change Value to Off. Click OK.

Protocol 3: RF Interference (Ekahau Sidekick Diagnostics)

If physical connections and power settings are correct, investigate network noise/interference (nearby power cables) or heavy Wi-Fi traffic. If using wireless devices, map the network channel using the Sidekick.

  1. Connect & Launch: Power on Ekahau Sidekick 2. Connect via USB-C to diagnostic iPad/Laptop. Launch Ekahau Analyzer app and sign in with Tarus credentials.
  2. Read the Spectrum: Navigate to Spectrum Analysis/Waterfall view. Filter to 5GHz band. Red/Orange = heavy utilization. Deep Blue/Black = empty and available.
  3. Walk the Machine Footprint: Physically walk the perimeter of the TARUS machine installation. Watch for a channel (e.g. 149 or 153) that remains "quiet" (Blue/Black).
  4. Select & Document: Identify the cleanest 20MHz wide channel. Program this channel number into the Hirschmann LanConfig software.

SINUMERIK 840D Solution Line: Reset Procedure

WARNING

Ensure the machine is in a safe condition before beginning. After any reset, verify axis limits, reference positions, and safety functions before returning to production.

Procedure 1 – NC & PLC Reset

Following this procedure before attempting firmware recovery can prevent unnecessary software installations and reduce machine downtime.

  1. Verify Startup: Power on. Observe NC 7-segment display. Should stop at: 6.
  2. Set Initial Dial Positions: Set NC Dial to 1, PLC Dial to 3. Reboot control.
  3. Switch NC to Normal Mode: Rotate NC Dial from 1 to 0. Verify LEDs:
    • READY: Flashing Green
    • STOP: Flashing Orange
    • SF: Solid Red
  4. Clear the PLC: Starting at PLC dial 3, perform sequence: 3 → 2 → 3 → 2. Leave in Position 2.
  5. Verify PLC Reset: READY (Flashing Green), STOP (Solid Orange), SF (OFF), 7-Segment (6).
  6. Complete Reset: Rotate PLC Dial to 0. Success = READY (Solid Green), RUN (Solid Green). Both NC and PLC are now cleared.

Creating an Archive in Operate

Step 1 & 2: Main Menu to Setup

From the Operate screen, select the M icon located in the upper-right corner. Then select Setup from the menu.

Step 3, 4, 5: Configure Archive

Navigate to Page 2. Select Take an Archive (bottom-left). Verify that all available checkboxes are selected (NCK, PLC, Drives, HMI). Verify option to Generate Archive and All Data is clicked.

Step 6, 7, 8: Save to USB

Enter descriptive name (e.g., Ford_2021_Before_7-14-26). Select your personal USB flash drive as storage. Press OK. Wait for 100%.

PLC Sign of Life Errors

Errors at top of screen are expected. System performs a PO Reset during archive. Do not panic or press cancel.

Commutation Angle Determination Guide

1 Unhide Siemens Control (If Necessary)

If Sinumerik Operate is already visible on the desktop, you can skip this step. Otherwise, navigate to:

C:\Program Files (x86)\Siemens\MotionControl\siemens\sinumerik\hmi\cfg

Look for the two configuration files. Select the active one and add - hide to its name. Then select the file ending in - show and remove that suffix. Make sure there are no spaces at the end.

2 Open Drive Parameters

  1. Open Operate (starts automatically with SProxy/TarusNC). Click the M button top right.
  2. Navigate to the Setup menu.
  3. Select Mach. Data at the bottom. Use page expansion if needed.
  4. Click Drive parameter.

3 Activate Commutation

Ensure you are looking at the correct axis/drive using Drive + / Drive -. Scroll down or search for parameter p1990.

Change p1990 from 0 to 1. An alarm message will appear stating the axis is ready. The check will automatically perform next time drives are enabled.

4 Perform the Check

Enable the drives. You will hear a quick audible buzz. If successful, p1990 reverts to 0. A "Save required" alarm will appear (ignore for now).

If Check Fails (Alarm 207995)

Cause 3: Angular change too large. Clear alarm and try again.
Causes 1, 2, 4X, 5: Usually indicates a physical wiring issue.

Monitor r1984

Parameter r1984 displays the difference between the last offset and the one you just measured. Perform the check 3-4 times. It will start large, but should approach 0.00. Keep performing until within ±4.00°.

5 Save Configuration & Verify

Once you have a good commutation angle, save your changes by clicking Save / Reset on the right. Then click Save, then Drive System.

Verify Machine Movement

Before moving under power, disable drives and turn head by hand to both hard stops. Ensure it moves freely 180.5° both ways. Click the M icon, select Machine, and monitor the axis position.

Schneeberger Encoder Battery Replacement

CRITICAL REQUIREMENT

The machine must always remain powered on during the battery replacement process. Do not power off.

1. Diagnostics & Evaluation

Review operator diagnostics screen. Inspect encoder indicator. Remove bird cage cover and check light pattern on the Schneeberger encoder.

Review the pattern against the chart. Green + Red Flashes = Backup Battery Empty.

2. Replacement Procedure

Remove rear cap (four small Allen screws). Remember, machine must remain powered ON. Replace batteries. Mark replacement date on new battery.

Verify and document old battery condition (check DC voltage with multimeter and record in notes).

Connecting to the Drive

Connect to the drive via RS232 communication cable. This cable has a DB9 on one end and a S-video type connector on the other. The S-video type connector is what plugs into the drive. The DB9 plugs into a PC.

Since most new PCs do not have an RS232 port on them anymore, you will have to use a USB to RS232 adapter to communicate.

Indraworks Software

Once the physical connection is made, open the drive software: Indraworks Ds or Indraworks Engineering.

  • To log onto the drive, select the RS232 connection type (both Ds and Engineering use both RS232 and Ethernet).
  • The COM port you select will depend on what the PC has assigned to the USB to RS232 adapter. You can use Windows Device Manager to check the COM port assignment and baud rate.

Resetting the Drive

1. Understand the Fault

Before resetting the drive you must understand why you are getting this fault. Just resetting the drive does not always fix the problem. Drive error codes will be displayed both on the drive and in the drive software. You can look these errors up in the drive help supplied on the PC.

2 Clear Error in Parameter Mode

To reset the drive you must first put the drive into parameter mode. You do this by clicking on the PM that is green in the upper middle of the drive page.

Once you are in PM (parameter mode) you can click the Clear error icon. This icon is located just to the left of the PM and is a red circle with an X and a check mark in the middle of it. This will clear all errors.

Now that your error is cleared you must return to OM (operating mode). Again this is located just to the right of the PM and will be green. Click on the OM and the drive will attempt to change into operating mode.

If the drive errors again you have bigger problems that need to be addressed.

Commutation of the Motor

1
Once you have the drive in OM most of our motors need to have the commutation offset found.
2
To do this you need to go into Drive control > Motor Control > Commutation settings.
3
In the commutation setting window you can find the offset by clicking on Determine Commutation Offset. (The drives must be in Ab to work or it will fault).
4
You can now continue with normal operation.
